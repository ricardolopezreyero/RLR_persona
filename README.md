## Reglas de la casa

1. Los artículos no se editan. Si un día escribo una versión nueva, se agrega como archivo nuevo con su fecha.
2. Todo lo que se publique a mi nombre sale de estos textos o de lo que yo diga; nada se inventa.
3. Los posts se proponen aquí, los reviso yo, y las fechas las decido yo.
4. Lo que aprendamos operando X, LinkedIn o YouTube se anota en `persona/VOZ-X.md` para no volver a aprenderlo.
